# Blueprint, MVP web

Versão web de teste do app Blueprint: monte o plano do dia, registre cada atividade com 1 toque e acompanhe o progresso.

Página única (`index.html`), sem build e sem dependências. Os dados ficam salvos no navegador (localStorage).

## Funções
- Monte seu dia: plano com quantidade, versão mínima, dias da semana e horário de lembrete
- Hoje: anel de progresso, Plano de hoje com 1 toque, registro fora do plano, "Outro" com nome, Desfazer
- Seu dia: pular atividades e acrescentar extras só hoje
- Calendário, Histórico (semana e mês) e Perfil (mapa de calor, Meu plano, tema e cor de destaque)

## Rodar localmente
Abra `index.html` no navegador.
